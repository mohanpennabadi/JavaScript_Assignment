# JavaScript Arrays and Strings

# push(), pop(), shift() and unshift()

push() adds an element to the end of an array.

pop() removes the last element from an array.

shift() removes the first element from an array.

unshift() adds an element to the beginning of an array.

# map() vs forEach()

map() creates and returns a new array after transforming each element.

forEach() executes a function for each element but does not create a new array.

# find() vs filter()

find() returns the first element that matches the condition.

filter() returns a new array containing all elements that match the condition.

# reduce()
reduce() processes all elements of an array and produces a single result.

Example uses include calculating totals, counts, sums, or other aggregates.
