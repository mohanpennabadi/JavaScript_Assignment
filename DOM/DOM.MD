# DOM Manipulation

## Purpose

DOM manipulation allows JavaScript to access and modify HTML elements dynamically.

### Important DOM Methods

* `getElementById()` selects an element using its ID.
* `querySelector()` selects the first matching element.
* `querySelectorAll()` selects all matching elements.
* `createElement()` creates a new HTML element.
* `textContent` gets or changes the text of an element.
* `classList` is used to add or remove CSS classes.

### Form Handling

JavaScript can read form values, validate them, create task records, and dynamically display them in a table.

### Validation

Validation messages can be displayed directly on the page instead of using `alert()`.

### Task Counts

The page displays the total, completed, and pending task counts dynamically.

### Empty State

When there are no tasks, the page displays `No tasks available`.
