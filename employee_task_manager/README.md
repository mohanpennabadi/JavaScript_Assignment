# JavaScript_Assignment
# Project Structure

1. This project is an **Employee Task Manager** made to help a company manage employee tasks.
2. The main goal is to add, view, search, update and delete tasks easily.
3. `index.html` contains the main content and layout of the application.
4. The top of the page shows the **Employee Task Manager** title.
5. Three small boxes show the total, completed and pending tasks.
6. The task form allows the user to enter employee details and task information.
7. The form includes Employee Name, Department, Task, Priority and Due Date.
8. A button is provided to add a new task.
9. A search box helps users quickly find an employee or task.
10. Department and Status options help users narrow down the displayed tasks.
11. The task list shows all the entered information in a table.
12. Each task has buttons to mark it as completed or delete it.
13. `style.css` controls how the application looks.
14. It makes the page clean, organized and easy to read.
15. It also makes the page adjust better on smaller screens.
16. `script.js` controls what happens when the user interacts with the application.
17. When a user adds a task, the information is collected and checked.
18. If any required information is missing, a clear message is shown.
19. After adding a task, it appears in the task list.
20. The application keeps the tasks saved in the browser.
21. This means the tasks can still be available after refreshing the page.
22. The application automatically updates the total, completed and pending counts.
23. Searching and filtering change the displayed tasks based on the user's selection.
24. The Complete button changes a task from pending to completed.
25. The Delete button removes a task from the task list.
26. The application also shows messages when there are no tasks or when information is loading.
27. Employee information is simulated as if it is being received from another source.
28. If something goes wrong while loading the employee information, an error message is shown.
29. Overall, the project brings all these features together into one simple application for managing employee tasks.
